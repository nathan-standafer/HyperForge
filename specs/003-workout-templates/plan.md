# Implementation Plan: Workout Templates & Programs

**Branch**: `003-workout-templates` | **Date**: 2026-04-15 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/003-workout-templates/spec.md`

## Summary

Add reusable workout templates (named exercise lists with target
sets/reps/weight), a "start from template" flow that pre-loads a
session, and weekly programs that suggest today's workout. Requires
new SQLite tables (templates, template_exercises, programs,
program_days, session_targets) and a schema migration. Integrates
with the existing session/set logging from feature 001; feature 002
progress tracking picks up template-started sessions automatically.

## Technical Context

**Language/Version**: TypeScript 5.x on Node.js 20+
**Primary Dependencies**: Expo SDK 52+, expo-sqlite (existing),
expo-router (existing), react-native-gesture-handler (existing)
**Storage**: SQLite via expo-sqlite — new tables + migration 002
**Testing**: Jest + ts-jest for unit tests (existing setup from 002)
**Target Platform**: iOS 15+ and Android 10+ (mobile-first)
**Project Type**: mobile-app
**Performance Goals**: Template list load <1s, session-from-template
start <1s, program suggestion on home screen <1s from app launch
**Constraints**: Offline-only, ≤3 taps to start a template workout,
single-user local, no new heavy dependencies
**Scale/Scope**: Single user, ~6 new screens/modals, ~4 new services,
5 new tables

**Structure Decision**: Extends the existing single-project Expo app.
New code in `src/services/`, `src/models/`, `src/components/`, and
two new route groups (`templates/`, `programs/`). Migration 002 adds
tables and alters the sessions table. Existing feature-001 write paths
(`session-service`, `set-service`) are not modified; the new
`session-template-service` wraps `createSession` then inserts
snapshot rows.
